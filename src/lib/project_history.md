# Журнал Проекта "AuraGroove"

### ЗАЧЕМ: ПЛАН №3050: CRUEL VOLUME CONTROL PROTOCOL
**СОБЫТИЕ**: Ликвидация всплесков громкости при смене тембров в канале LEAD.
**ЧТО**: 
1. В `audio-engine-context.tsx` внедрена унифицированная калибровка преампов: менеджеры теперь наследуют `SAMPLER_DEFAULTS` множители, выравнивая уровень синтезаторов с сэмплерами.
2. Добавлена процедура `syncMixerNodes` при инициализации для мгновенного применения уровней из `localStorage` к аудио-узлам.
3. Начальный преамп менеджеров V2 снижен до `0.1` ("Safe Start").
4. В `instrument-factory.ts` установка `instrumentGain` переведена на `setValueAtTime` для предотвращения скачков при создании новых голосов.
**РЕЗУЛЬТАТ**: Смена инструментов происходит плавно, без изменения субъективной громкости. Микшер теперь "жесточайше" контролирует выход каждого канала.

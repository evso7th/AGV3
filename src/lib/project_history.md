### ЗАЧЕМ: ЛИКВИДАЦИЯ УТЕЧЕК ПАМЯТИ (THE GREAT PURGE)
**СОБЫТИЕ**: Глобальное укрепление герметичности звукового движка.
**ЧТО**: 
1. Внедрен протокол **AudioParam Unlink** в `instrument-factory.ts`. Теперь входящие LFO-связи разрываются принудительно.
2. Введена система **AbortController** для всех `setTimeout` в менеджерах. Таймеры больше не "сиротствуют".
3. Исправлены замыкания в сэмплерах через обнуление `onended` обработчиков.
4. Принудительная остановка LFO-осцилляторов при уничтожении инструмента.
**РЕЗУЛЬТАТ**: Количество узлов в AudioGraph теперь строго соответствует количеству звучащих нот. Система готова к многочасовым сессиям без деградации.

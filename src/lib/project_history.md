### ЗАЧЕМ: ПРЕДОТВРАЩЕНИЕ УТЕЧЕК ПАМЯТИ (AudioParam Unlink)
**СОБЫТИЕ**: Внедрение протокола принудительного разрыва связей с AudioParam.
**ЧТО**: 
1. В `instrument-factory.ts` добавлен массив `paramLinks` для каждого голоса.
2. Метод `hardKill` теперь принудительно вызывает `src.disconnect(param)`, разрывая связи LFO -> Filter.
3. Добавлена очистка и остановка системных LFO осцилляторов при удалении инструмента.
**РЕЗУЛЬТАТ**: Полное устранение накопления "мертвых" фильтров в аудио-графе. Теперь даже многочасовые сессии остаются стабильными и потребляют фиксированное количество памяти.
